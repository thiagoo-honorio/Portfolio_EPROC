Os 10 Princípios do Tratamento de Dados

Todo tratamento de dados pessoais na universidade deve observar a boa-fé e estes princípios fundamentais. Clique em cada princípio para ver exemplos práticos.

Como Embedar esta Seção

1

Extraia o ZIP exportado. Os arquivos ficam: index.html, styles.css, script.js e card_exemplos_principios_lgpd_data.json.

2

Copie os 4 arquivos para uma pasta dentro do seu projeto (ex.: ./secao-lgpd/).

3

No HTML da página onde quer embedar, cole o snippet abaixo no local desejado:

<!-- Seção LGPD -->
<iframe src="secao-lgpd/index.html" width="100%" height="800" frameborder="0"></iframe>
4

Alternativa sem iframe — copie o conteúdo de cada arquivo e cole nos seus próprios arquivos (HTML no body, CSS no head, JS antes de </body>).

5

Certifique-se de que o card_exemplos_principios_lgpd_data.json está na mesma pasta do index.html exportado.
